# FlashHUD




A customizable Hunter toolkit for **WoW Forever**, made by Flash.




## Downloads and patch notes




**[Open downloads and full patch notes](https://github.com/Houlberg86/FlashHUD/releases)**




The first downloadable ZIP is coming soon. When a release is available, open its **Assets** section and download the attached `FlashHUD` ZIP.




## Features




- Pet health, focus and happiness HUD, Feed Pet button and pet-action keybinds.
- Cast bar, Auto Shot and melee swing timers, range display and Mana bar.
- Customizable cooldown rows, target Sting timers and glow options.
- Reminders for ammo, durability, Growl, missing pet or Aspect, and low pet health.
- Gun and bow sound muting, auto-repair, junk selling and ammo restocking with confirmation.
- Saved profiles and flexible layout settings.




## Installation




1. Download the packaged FlashHUD ZIP from **Releases → Assets**.
2. Extract the `FlashHUD` folder into your WoW `Interface/AddOns` folder.
3. Check that `FlashHUD.toc` is directly inside `Interface/AddOns/FlashHUD`.
4. Restart WoW and enable FlashHUD in the character-selection AddOns menu.




Right-click the minimap button to unlock and move the HUD.
